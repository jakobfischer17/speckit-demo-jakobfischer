# Productivity Hub

A React SPA (Single Page Application) for productivity enhancement, featuring:

## Features

### 🍅 Pomodoro Timer
- Work sessions (25 minutes default)
- Short breaks (5 minutes)
- Long breaks (15 minutes)
- Custom timer settings
- Browser notifications when time is up
- Start/pause/reset controls

### 💡 Productivity Tips
- 10 curated productivity tips
- Interactive navigation (previous/next)
- Quick access grid to all tips
- Tips covering focus, breaks, goal-setting, and more

### 🧘 Breathing Exercises
- Three breathing techniques:
  - **Box Breathing**: 4-4-4-4 pattern for focus and calm
  - **4-7-8 Breathing**: For relaxation and sleep
  - **Energizing Breath**: Quick cycles to boost energy
- Animated visual guide
- Phase-by-phase instructions
- Countdown timer for each phase

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm preview
```
